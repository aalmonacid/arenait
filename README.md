# ArenaIT
Ingeniería de Software Estructural para Operaciones Críticas

> Para el estado real del proyecto (qué funciona, qué falta, bugs conocidos), ver [`CONTEXT.md`](./CONTEXT.md). Para el plan de trabajo priorizado, ver [`BACKLOG.md`](./BACKLOG.md).

## Propuesta de Valor
- Resiliencia operativa
- TCO -35% a -40%
- SLA 99.999%
- ISO 27001, TOGAF, ISO 25010, FinOps

## Stack Tecnológico
- Astro 5.0
- Sanity.io (CMS Headless)
- Tailwind CSS (Styling)
- TypeScript

## Iniciar Proyecto
1. Copiar `.env.example` a `.env`
2. Ejecutar `npm install`
3. Ejecutar `npm run dev`

## Guidelines de Diseño (Swiss Minimalist)
- **Colores**:
  - Primario: #0075C9 (Azul Cerúleo)
  - Secundario: #294E6C (Azul Noche / Pizarra)
  - Acento: #FEA621 (Naranja Ámbar)
  - Interactivo: #0446F1 (Azul Eléctrico)
  - Neutros: #FFFFFF, #F8FAFC, #E2E8F0, #0F172A
- **Tipografía**: Codec Pro Extra Bold (Titulares), Codec Pro (UI/Cuerpo).
- **Prohibido**: Estéticas cyberpunk, gradientes de neón o fondos oscuros estilo matriz.
- **Enfoque**: Diseño limpio, corporativo y de alto contraste WCAG AAA.
